## Domeniu livrat

P8.4 introduce contractul versionat `atlas-export-v1` și:
- export GeoJSON individual, fără simplificare sau reparare geometrică;
- export metadata JSON/CSV;
- export rezultate de comparație geometrică JSON/CSV;
- export măsurări JSON/GeoJSON;
- export SVG vectorial al hărții;
- imprimare/PDF A4 portret și landscape;
- raportarea problemelor din cardul entității prin GitHub Issues;
- atribuirea și proveniența necesare.

PNG nu este implementat intenționat. SVG/PDF sunt vectoriale și exclud explicit rasterul OSM.
