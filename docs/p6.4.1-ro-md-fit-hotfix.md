# P6.4.1 — Hotfix încadrare România–Moldova

**Baseline exact:** `main` `325e95966bc618ceaaca37d4d65133b7e14da66a` (P6.4 final PASS). Branch separat `web/p6.4.1-ro-md-fit-bounds-zoom-control`.

## Cerință vizuală

Pe telefon Android/Chrome, inclusiv în capturile utilizatorului, butonul vechi „Centrare RO + MD” seta lat/lon/zoom prestabilite și putea tăia partea vestică a României. Un viewport cu centru fix nu garantează includerea ambelor țări pe toate raporturile de aspect.

## Remediere

1. Limitele reale sunt obținute din `map.bbox` ale celor două entități-rădăcină ACTUAL existente `osm-r58974` și `osm-r90689`, validate numeric și reunite ca **union bounding box** pentru Leaflet `fitBounds`. Nu se alterează geometria sursă și nu se derivează o graniță nouă.
2. Prima încărcare fără parametri de poziționare expliciți în URL încadrează ambele entități. Linkurile `?v=1&lat=...&lon=...&z=...` rămân identice și nu sunt reîncadrate automat; selecțiile de entități din URL continuă contractul existent.
3. Comanda devine un icon SVG cu nume accesibil, atașat **direct sub zoom + și −, în același control Leaflet**, țintă tactilă minimum 44×44 px. Recentrările explicite folosesc `atlasUrl.action('push',...)`, astfel încât Back/Forward readuce vederea precedentă.
4. Spațiul de siguranță este dimensionat separat pentru telefon portret, telefon landscape scund și desktop/tabletă. Butonul nu modifică selecția, filtrele, geometria bifată sau activarea independentă a fundalului OSM.
5. Politica URL existentă folosește niveluri de zoom întregi; nu se schimbă `zoomSnap` sau `validViewport`, evitând ruperea linkurilor canonice.

## Acceptare obligatorie

- Browser Chrome pe **390×844, 360×640, 430×932, 844×390, 768×1024, 899×768, 900×768, 1440×900**. Testul folosește proiecția Leaflet a colțurilor bounding box-ului real RO+MD în coordonate de ecran pentru a confirma că ambele țări sunt integral în map viewport, nu doar că lat/lon au valori apropiate.
- Icon în același control cu zoom +/−, poziția imediat sub ele, accesibil prin tastatură și ecran tactil; fără overflow orizontal.
- Test pentru **URL cu viewport explicit** (trebuie păstrat la prima încărcare), home după pan/zoom și Back/Forward, OSM raster independent și entitate selectată dar nebifată.
- Required frontend-browser-qa, P2, release trust ACTUAL, CodeQL JS/TS și Actions, topologie și gate-ul ACTUAL de reproducibilitate. Merge numai după PASS pe SHA exact.
- Post-merge: GitHub Pages, Chrome live portret/landscape + regresii P4/P5/P6; **toate GeoJSON publice 123/123 și resursele frontend byte-identice** cu obiectele Git din commitul de merge.

**Limită:** testele Chrome pe viewport mobil emulat nu echivalează cu certificarea dispozitivului fizic/VoiceOver/TalkBack. Geometriile OSM EPSG:4326 nu sunt simplificate sau mutate.
