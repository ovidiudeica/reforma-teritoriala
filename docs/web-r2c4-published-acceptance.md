# WEB-R2c.4 — acceptarea finală a website-ului publicat

Predecesor acceptat: WEB-R2c.3.2, PR #392, `main@970ce9ad70273c3b34721c283075875b04e1a2a3`. Gate-uri post-merge: 14 workflow-uri și 21 checks PASS, fără omiteri; audit public 39385100647 PASS cu 18 verificări, 14 capturi inspectate și nouă hashuri publicate potrivite. Cele 32 componente ACTUAL, 5.848 identități și 85 roluri sunt intacte. Dosarul post-merge al etapei închide GATE-002.

Această etapă extinde acceptarea pe GitHub Pages: pornire în viewport-ul declarat, desktop/tabletă/mobil portrait/landscape, selecții RO → MD → NI, geometrii și jurisdicții independente, filtre OSM 8/9 și statistice, confirmare/anulare/Undo, interacțiuni repetate, Back/Forward, refresh/Share, căutare/carduri, fundal OSM, focus și zoom nativ 200%. Se verifică resursele runtime și geometrice publicate față de sursele checkout-ului corespunzător și se păstrează hashurile și diagnosticele brute de rețea/consolă.

Auditorul candidat și sursa publicată se identifică separat. În PR, domeniul public este baseline-ul integrat; aceasta nu certifică publicarea candidatului. După merge este obligatoriu verdictul `PUBLISHED_EXACT_CHECKOUT` pentru noul main, împreună cu CI și Pages pe acel SHA.

Orice problemă reproductibilă nouă se înregistrează și se remediază cu regresie. Acceptarea finală necesită toate gate-urile, capturile relevante inspectate și zero defecte tehnice cunoscute deschise. Nu se schimbă UX fără un contract verificat. ACTUAL, părinții juridici MD, geometriile și P9.1 rămân protejate; acceptarea semantică rămâne BLOCKED_INCOMPLETE.

Rularea [39390379936](https://github.com/ovidiudeica/reforma-teritoriala/actions/runs/39390379936), auditor `6216178a96cf0f790d1348d5a1108f0838fbc84d`, trece pe baseline-ul publicat `970ce9ad70273c3b34721c283075875b04e1a2a3`. Inventarul urmărit de Git cuprinde 433 resurse, 125 GeoJSON și 277.099.270 octeți comparați SHA-256. Se păstrează calea reală `public/` a resurselor; fișierele neurmărite nu sunt tratate drept resurse publicate. Verificarea este read-only, cu maximum șase cereri simultane și refuz la HTTP diferit de 200, redirect sau hash necorespunzător.

Scenariile adăugate verifică prin pointer bifele celor două rădăcini ACTUAL și ale tuturor celor opt contururi NI, separat de selecția cardului; filtrul statistic 1 independent de OSM 8/9; cele trei comutatoare de jurisdicție; resetarea geometriilor fără resetarea filtrelor/selecției și resetarea filtrelor fără resetarea geometriilor/selecției. Matricea include patru porniri la viewport-ul declarat și două ferestre cu zoom nativ 200%. Regresiile unitare refuză resurse învechite chiar și cu HTTP 200 și păstrează diagnosticul unui 404.

RM-008 a fost un defect al noului scenariu: după selecția unui card pe tabletă, panoul Entități se închide conform UX existent, dar auditorul încerca un checkbox ascuns. Originalul eșuat [39389258992](https://github.com/ovidiudeica/reforma-teritoriala/actions/runs/39389258992) se păstrează; remedierea redeschide panoul prin controlul public înainte de secvența individuală. Retestarea celor patru profiluri trece. Aplicația și corpusul nu au fost modificate în acest PR.

RM-009: auditul dependențelor a identificat încă două resurse runtime: biblioteca și manifestul `vendor/gis` importate de workerul geometric existent. Inventarul anterior de 433 este păstrat ca dovadă parțială, nu drept acceptare integrală. Noua regresie eșuează pe helperul `e8f418c` atât pentru absența dependenței GIS, cât și pentru acceptarea unei biblioteci învechite; helperul corectat trece toate cele nouă teste. Inventarul complet este de 435 resurse, inclusiv 125 GeoJSON, total 277.599.622 octeți. Retestarea publică [39393411861](https://github.com/ovidiudeica/reforma-teritoriala/actions/runs/39393411861) trece pe `310e05f6b8d871eaafc64e1f89df17b7584fb6af`, împreună cu matricea de 69 înregistrări / 52 capturi. Gate-ul pe head-ul final exact rămâne obligatoriu înainte de integrare.

Limitele rămân explicite: profiluri Chromium pe runner, nu dispozitive fizice; arbore AX, nu certificare cu cititor de ecran; zoom nativ de pagină separat de mărirea fonturilor P7.6 din suita locală obligatorie; comparație de resurse pe intervalul rulării, nu snapshot global atomic al CDN-ului. Dependențele Leaflet externe sunt fixate în HTML prin versiune și SRI; inventarul SHA-256 de mai sus privește resursele self-hosted, nu rasterele OSM terțe.

Stare: acceptarea integrării rămâne condiționată de toate gate-urile pe head-ul final, inspecția capturilor, auditul diff și verificarea post-merge CI/Pages cu `PUBLISHED_EXACT_CHECKOUT`. Etapele NI-JUR nu au început.
