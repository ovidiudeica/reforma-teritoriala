# P6.4.2 — Comutatorul fundalului OSM în bara Leaflet

**Baseline exact:** `main` `4177b09c195e792677ef0f757168ba7ca21b834e` (P6.4.1 închis/PASS). Branch izolat: `web/p6.4.2-osm-toggle-zoom-control`.

## Contract de UI

- Ordine verticală în controlul Leaflet: **zoom +**, **zoom −**, **încadrare România+Moldova**, **fundal OSM**.
- `#basemap-toggle` este mutat prin DOM în același `.leaflet-control-zoom` după `#map-home`, fără control Leaflet nou și fără duplicare.
- Icon SVG nativ, cu hartă stilizată. Fundal activ: icon cu mapă fără bară; fundal dezactivat: aceeași mapă barată diagonal. Culoarea de fundal ajută, dar forma rămâne distinctă și în forced-colors.
- `aria-pressed`, `aria-label` și `title` reflectă starea reală. SVG este decorativ (`aria-hidden`). Butonul este accesibil prin tastatură și are minimum 44×44px pe toate viewporturile.
- Comutatorul continuă să manipuleze **doar** stratul raster OSM; nu schimbă entitățile bifate, selecțiile, filtrele, geometriile, focusul sau centrarea hărții. URL-ul existent `m=0` și istoricul Back/Forward rămân conforme.
- CSS nou, încărcat ultimul, suprascrie poziționarea absolută veche P5.3 și regulile de explorator P6.3 pentru a împiedica suprapunerea cu butoanele vizuale.
