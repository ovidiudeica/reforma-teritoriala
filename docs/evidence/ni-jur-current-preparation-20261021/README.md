# Dosar individual pregătitor — 85 de roluri

Acest pachet continuă pregătirea independentă cu sursele recapturate la 21 octombrie 2026. Nu declară NI-JUR.0–4 acceptate și nu depășește dependența OSM-FIX.2.

Fiecare rol are cinci axe: identitatea cartografică, geometria/topologia, organizarea operațională revendicată, apartenența administrativă de jure și certificarea documentară contemporană. Controlul efectiv are un verdict separat; nu decide apartenența juridică. Obiectele juridice MD și părinții geometrici sunt păstrați din intrarea istorică, fără inferențe sau noi atribuiri.

Toate cele 93 de geometrii recapturate corespund referințelor protejate; 4.278 de perechi au fost verificate, fără suprapuneri de interior sau egalități. Captura nu este atomică. Sursele originale și digesturile artefactelor se găsesc în `roles/`, `outlines/` și `provenance/` ale acestui pachet.

Reproducere din acest director:

```text
node generate.mjs --self-test
node generate.mjs --write
node generate.mjs --check
```

Intrările sunt fixate prin SHA-256 în generator. Regenerarea este byte-identică, fără rețea sau acces de scriere în corpus. Manifestul include hashul generatorului și hashuri individuale pentru toate cele 85 de roluri.

Verdictele administrative și juridico-documentare rămân nerezolvate în limitele probelor. Registrul contemporan complet și controlul fiecărui poligon nu sunt certificate. Dosarul nu autorizează mutații ACTUAL sau P9.1.
