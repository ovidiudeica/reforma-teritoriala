Baseline de reconciliere: `main@54a4ed95c9c80edc7406cbb9c52fdf906a67b9cd`. Domeniu: registru descriptiv separat pentru opt contururi operaționale OSM și 85 de roluri care reutilizează identitățile/geometriile ACTUAL existente. Grupările geometrice de verificat sunt Camenca 13, Rîbnița 23, Dubăsari 10, Grigoriopol 16, Tiraspol 3, Slobozia 16 și Bender 4. Nu se deduce apartenența administrativă revendicată sau juridică din geometrie.

Manifestul `ni-jur0-inventory-manifest.json` leagă fiecare rând și fiecare sursă prin SHA-256. Identificatorii omonimi Bender și Hlinaia rămân distincți. Cremenciug păstrează separat părintele juridic CUATM 2700, gruparea geometrică Slobozia și revendicarea istorică Tiraspol. Pentru Lunga sunt consemnate probele istorice de microraion și absența nominală din anexa analizată.

Cele 85 XML-uri istorice sunt verificate individual față de arhiva acceptată și reconciliate cu recensământul tagurilor, catalogul rolurilor, matricea semantică și ledgerul. Pentru cele opt contururi, originalele API ale versiunilor istorice fixate au fost accesate la 20 octombrie 2026 și păstrate în `ni-jur0-outline-metadata.json`; versiunile, timestampurile și hashurile membrilor corespund dovezilor acceptate. Aceste capturi verifică metadatele istorice, fără recapturarea geometriei ori certificarea OSM curente. Aliasurile de căutare UI sunt separate de numele OSM și de afirmațiile juridice.

Există 84 de potriviri nominale în dovezile istorice 2023; acestea nu certifică un părinte administrativ contemporan. ID-ul OSM de părinte copiat din ledgerul istoric al proiectului este etichetat explicit ca un crosswalk intern, fără autoritate de identificator în documentul primar. Anexa normativă numește regiunea; nu emite ID-uri OSM. Nu se completează identificatori noi prin geometrie ori nume. Lipsa unei probe contemporane se consemnează explicit; verificarea OSM live aparține NI-JUR.1, iar adjudecarea documentară NI-JUR.2–3.

Generatorul `scripts/audit/ni-jur0-inventory.mjs` reproduce byte-identic registrul și manifestul. Auditul CI impune surse Git curate și SHA exact. Cele nouă probe negative resping duplicări, modificări de părinte juridic, atribuirea din geometrie, pierderea aliasurilor, versiuni false, comasarea Bender, promovări juridice/P9.1 și niveluri inventate. Testele parserului verifică entitățile XML, membrii ordonați, tagurile duplicate, referințele invalide și integritatea prototipului. Nu se modifică ACTUAL, părinții MD, geometriile, politicile de promovare sau website-ul. `actual_mutation_allowed=false`, `p91_import_allowed=false`, `semantic_acceptance=BLOCKED_INCOMPLETE`.
