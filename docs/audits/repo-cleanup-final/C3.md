# C3 — igienă sigură, fără pierdere de surse

Stare la redactare: **VERIFIED_LOCALLY_PENDING_CI**. Acceptarea ulterioară este consemnată în registrul de progres și raportul final. Schimbare separată de graful C2 și de consolidarea CI. ACTUAL și resursele runtime nu sunt modificate.

## Eliminare individuală

Unicul fișier eliminat: `scripts/process/.gitkeep`, **0 octeți**, Git blob `e69de29bb2d1d6434b8b29ae775ad8c2e48c5391`, SHA-256 `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`.

Rolul său era exclusiv păstrarea unui director inițial gol. Directorul conține acum **71 de scripturi `.mjs`**, versionate separat. Git păstrează directorul prin acele fișiere. Placeholderul nu este cod, sursă, geometrie, configurație sau dovadă originală; nu aparține celor 478 de fișiere protejate sau celor 440 de resurse runtime.

În snapshotul C2 are zero referințe directe și 27 de posibilități conservatoare de director. Acestea provin din documentarea directoarelor, construirea rădăcinilor URL și cititori de dovezi/scripts cu ținte proprii; nu reprezintă 27 de importuri ale placeholderului. Referințele exacte din versiunea curentă sunt inventare istorice și un fixture al clasificatorului care testează o cale ca șir, fără să citească sau să ceară existența fișierului. Inventarele istorice rămân neschimbate: ele descriu corect momentul lor.

Test demonstrativ: în checkoutul rezultat `scripts/process/` există, toate cele 71 de module rămân, nu apare nicio schimbare de blob în seturile protejate/runtime, iar toate testele și workflow-urile existente trebuie să treacă. Niciun manifest ACTUAL, registru probatoriu istoric sau test nu este rescris pentru a tolera ștergerea.

Decizie per-ID: **SAFE_TO_DELETE**, exclusiv pentru acest placeholder gol, pe baza rolului în Git, a conținutului nul, a directorului populat și a verificărilor de consumatori. Aceasta nu reclasifică automat alte fișiere fără referințe. `data/historical/.gitkeep` și `data/proposals/.gitkeep` rămân păstrate pentru modulele viitoare.

## Cache-uri Python

`.gitignore` adaugă exclusiv `__pycache__/`, `*.pyc` și `*.pyo`: rezultate de compilare Python regenerabile. Nu există fișiere urmărite care să corespundă acestor forme. Testul `git check-ignore --no-index --stdin` confirmă ignorarea celor trei forme și păstrarea eligibilității fișierelor `.py` și a manifestului ACTUAL. Nu se adaugă o regulă generală pentru `outputs/`, care ar putea ascunde intrări/audituri neelucidate, și nu se ignoră extensiile native `.pyd`.

Nu se pretinde economie de conținut Git prin ștergerea unui blob gol. Câștigul este eliminarea unui placeholder devenit redundant și prevenirea introducerii accidentale a cache-urilor generate. Celelalte copii probatorii, prototipuri și unelte manuale sunt păstrate conform registrului C2.

În checkoutul local, cele 41 de rezultate neversionate existente în `outputs/` (18.446.389 octeți) au fost păstrate integral în directorul de lucru din afara clonei. SHA-256 al fiecărui fișier a fost verificat înainte și după mutare. Aceasta este igienă locală reversibilă, fără ștergere de dovezi și fără reducere pretinsă a dimensiunii arborelui Git. Rapoartele livrate anterior utilizatorului rămân pe căile lor de livrare.
