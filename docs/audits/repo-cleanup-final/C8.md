# C8 — securitate și păstrarea dovezilor

Cele două referințe mutabile Actions rămase în workflow-ul istoric RT-ADM.2.13.1 sunt fixate la commiturile rezolvate de tagurile oficiale v4/v5. Nu se schimbă evenimentele, permisiunile, comenzile sau intrarea canonică existentă; auditul geografic istoric nu este relansat.

Inventarul read-only citește bloburile Git și payloadurile gzip/tar limitate la 64 MiB. Raportul emite numai cale, linie, regulă și dispoziție, fără valori detectate. Cele două recepise originale au SHA-256 fixat și URL-uri de descărcare expirate la 24 octombrie. Doar acele bloburi exacte sunt recunoscute ca dovezi istorice; orice modificare sau semnătură nouă cere REVIEW_REQUIRED și exit nenul. Alertele GitHub rămân deschise. Expirarea URL-ului nu dovedește revocarea credențialei terțului. Nu s-au șters ori rescris probe.

Regresiile verifică redacția și faptul că aceeași cale cu alt conținut nu primește derogare. Scanarea și regresiile sunt adăugate la jobul browser, fără eliminarea vreunui gate. `c8-security-report.json`, `c8-alert-summary.json`, `c8-npm-audit.json` și `c8-provenance.json` fixează observația și implementarea. Nicio scanare de semnături nu certifică absența universală a secretelor sau datelor personale; arhivele imbricate/OCR nu sunt interpretate exhaustiv.

Reproducere: `python scripts/audit/test_cleanup_security_signatures.py`, apoi `python scripts/audit/cleanup-security-signatures.py --ref COMMIT --as-of TIMESTAMP --out outputs/cleanup-final/security.json`. Folosește commitul și timestampul din raport. npm audit este o observație datată a registrului, nu o garanție perpetuă.
