## Proba registrului extern

`https://pravopmr.ru/` a răspuns HTTP 200; documentul HTML al paginii inițiale, capturat local, avea 176.085 octeți, SHA-256 `772fc2a1ca7b7de7d4d235e30aff87053524dcbdefb641a7a4816d1952c40cbb`. **Nu a fost arhivat în Git**, astfel că hashul este numai observație locală, nu dovadă primară transportabilă. Fiind un serviciu privat, `pravopmr.ru` avertizează explicit că textele nu sunt autentice și nu își asumă responsabilitatea pentru erori. Interfața dispune de filtre după „organ adoptant” și „tip act”, dar nu a fost recuperat un export complet, verificabil, mapabil 1:1 la cele 9.254 de publicații. Există și mecanisme de control al accesului; nu s-a încercat evitarea lor.

Această sursă poate genera **candidați pentru reconciliere**, nu identități juridice certificate fără confruntarea cu un original oficial. Pentru comparația central–extern, toate numerele diferențelor rămân `null`: absențe, duplicate, contradicții, acte existente exclusiv extern și acte inaccesibile. `null` nu înseamnă zero.

## Instrumentul de recuperare

`docs/p9.0.7.2.10.2-probe-official-cards.mjs` citește registrul hash-pinned, selectează exclusiv rânduri încă necertificate, folosește gazde oficiale prestabilite, un prag strict de maximum **25 de înregistrări per execuție**, timeout limitat la 2–15 secunde și pauze între cereri. Nicio asociere emitent–publicație nu este inferată din tip, titlu sau text de pe un site neautentic. Orice fișă HTML disponibilă este păstrată brut, cu SHA-256 și UNID; chiar dacă prezintă identificatorul corect, starea este **`ARCHIVED_MATCHED_ID_UNCERTIFIED`**, nu `CERTIFIED`, până la verificarea explicită a emitentului, a conținutului și a provenienței. Jurnalul este scris într-un director extern checkout-ului, numai cu `--out` explicit.

Exemple de rulare pe o copie locală ce conține sursele:

```bash
node docs/p9.0.7.2.10.2-probe-official-cards.mjs --self-test
node docs/p9.0.7.2.10.2-probe-official-cards.mjs --year=2026 --offset=2 --limit=6 --timeout-ms=8000 --out=/tmp/p9072102-2026-2
```

Nu se reia continuu într-o buclă un server care expiră și nu se automatizează traversarea controalelor de acces ale serviciului privat. Execuțiile suplimentare sunt justificate numai în condiții normale de acces, cu jurnal de captură și probă oficială. Pentru fiecare emitent nou se impun identificator publicație, UNID concordant, fragmentul explicit din fișa oficială ori documentul original, hashul fișei și validare independentă înainte de promovarea în registrul probatoriu.
