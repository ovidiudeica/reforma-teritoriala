## 3. Riscuri, prioritizare și următoarele acțiuni

**P0 (blocante pentru integritate):** niciunul confirmat în fluxurile testate.

**P1 (UX / conformitate înainte de release closure P5):** clarificarea pragului tabletă 721–899px pentru drawer versus sidebar; introducerea unui control global de reset filtre; verificarea interacțiunii cu selecția ascunsă pe mobil și a unei acțiuni directe de activare.

**P2 (finisaje):** buton PROPUNERI dezactivat conform contractului, localizarea `inactive` → `inactive/ dezactivate` în română, țintă tactilă ≥44px, criteriul de persistență a lățimii între reloaduri și selectorul read-only pentru corpus/release.

**Decizie:** P5.3 este închis oficial în PR #270 după A/B post-merge PASS; P5.4 rămâne **în audit/remediere**, nu se declară faza P5 închisă până la rezolvarea P1, testare finală și PR separat cu 6 required checks `strict=true`.

## 4. Contract de lucru P5.4

- Branch și PR **separate** de P5.3.
- Nu se schimbă datele/OSM, topologia sau sursele ACTUAL/P2, nici canonizarea geometrică.
- Se păstrează A/B deterministic reproducibility, CodeQL, P2, release trust, topology, browser QA și Pages live integrity.
- După orice remediere UX se repetă 7 viewporturi, URL/History, keyboard/aria, 5.848 × 170, 123/123 asseturi, comparație A/B și browser pe URL-ul publicat.

Auditul reprezintă diagnosticul de intrare în P5.4, nu aprobarea închiderii întregii faze.

Testele read-only pot fi rulate explicit, fără să fie adăugate la gate-urile PR care nu trebuie să depindă de rețeaua publică:

```sh
node --test scripts/audit/p54-pages-smoke.mjs
node --test scripts/audit/p54-pages-accessibility.mjs
node --test scripts/audit/p54-geometry-integrity.mjs
```

Ultimul script execută exclusiv binarul fix `git` din `PATH` cu argumente constante; pe Windows se adaugă directorul Git la `PATH` înainte de execuție. Creează raportul JSON cu SHA-256 și Git blob SHA-1 la o cale fixă în directorul temporar (`p54-public-geometry-integrity.json`), fără a accepta override de comandă sau cale prin variabile de mediu. Verifică exact cele 115 chunk-uri și cele 8 fișiere geometrice ACTUAL de overview/local/detail/statistice.

Testele Chrome de pe Pages sunt suplimentare, pentru **post-deployment**; nu înlocuiesc P4.2, regresiile P5, sau comparația A/B obligatorie în GitHub.
