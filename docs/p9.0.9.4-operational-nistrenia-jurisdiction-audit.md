# P9.0.9.4 — Nistrenia, a treia jurisdicție *operațională* în interfață

## Audit de impact (baseline `main@2054266428c6017bd3eb1918ccfa1d6d32288b27`)

1. `public/data/actual-consolidated-tree.json` conține **5.848 de noduri** și două rădăcini juridice, România și Moldova. Validatorul `atlas-hierarchy-validate.mjs` impune explicit cele două jurisdicții. Alterarea acestuia sau a surselor ACTUAL ar promova implicit identități necertificate, interzisă prin politica P9.1.
2. `public/data/p907216-osm-roles.json` inventariază **85 de roluri OSM descriptiv-cartografice**, deja legate de **85 de ID-uri ACTUAL existente** (MD). `public/data/p909-nistrenia-osm-navigation.json` documentează **7 grupuri geometrice OSM** (Camenca 13, Rîbnița 23, Dubăsari 10, Grigoriopol 16, Tiraspol 3, Slobozia 16, Bender 4). Rădăcina OSM `65335` nu are o nouă geometrie ACTUAL; nu se calculează sau importă un poligon de stat.
3. `app.js` admite doar `RO` și `MD` ca filtre ale renderer-ului Leaflet și în starea URL. Elementele OSM erau accesibile numai într-un panou secundar, iar entitățile sursă apăreau exclusiv în arborele juridic MD.
4. Alegerea modelului: păstrăm **arborele juridic ACTUAL intact**, iar `atlas-nistrenia-jurisdiction.mjs` produce o **proiecție de UI**: o a treia rădăcină `view-nistrenia`, șapte noduri de grupare și 85 de aliasuri de navigare care indică fiecare exact același ID geometric ACTUAL. Orice alias are un ID `view-...` imposibil de confundat cu o entitate legală. `entityById` și `hierarchyNodeById` rămân neschimbate. Geometria nu se duplică în memoria hărții: aliasurile doar selectează/vizibilizează poligoanele originale.
5. Pentru jurisdicțiile din Filtre, `NI` este un **filtru operațional al interfeței**, nu o valoare de jurisdicție din corpusul ACTUAL. Când `NI` este activ, vizibilitatea celor 85 de geometrii aparține filtrului NI, independent de MD; aceeași infrastructură Leaflet MD le furnizează *fizic*, fără import nou. Pornirea NI nu modifică bifa MD. Valorile `NI` sunt serializabile în URL, iar linkurile RO/MD vechi rămân compatibile.
6. Căutarea grupează suplimentar rădăcina, cele 7 grupări și aliasurile geometrice sub **„Nistrenia”**. Activarea unui alias duce la cardul și geometria ACTUAL deja existentă; cardul distinge jurisdicția oficială MD de clasificarea de facto operațională. Selectarea rădăcinii sau unui grup face zoom la *bounding box*-ul geometriei existente, nu la un contur nou.
7. **Fail-closed:** validatorul celor 85 de roluri, proveniența OSM și inventarul ACTUAL sunt precondiții obligatorii. Fără ele, NI rămâne dezactivată, nu se generează identități, geometrii sau părinți de facto pe baza unor date neverificate. P9.1 rămâne blocat.

## Criterii de acceptare

- Arbore: rădăcini UI România / Moldova / Nistrenia; Nistrenia conține exact 7 grupuri și 85 de aliasuri distincte; fără schimbarea celor 5.848 de entități ACTUAL.
- Filtre: checkbox separat „Nistrenia”, implicit debifat; comutarea independentă NI/MD; URL `j=NI` păstrat prin History/Share; filtrele nu șterg bifele entităților.
- Hartă: toate geometriile sunt citite numai din chunk-urile și overview-urile ACTUAL MD deja autorizate; nicio nouă cerere `nistrenia*.geojson`, niciun contur 65335 inventat; zoom și selecție reală la subdiviziuni.
- Căutare/card: entitățile pot fi accesate sub Nistrenia, dar cardul reține explicit identitatea juridică MD și lipsa certificării de facto.
- Desktop/mobil: Chromium la 1440×900, 390×844 și 844×390, arbore virtual accesibil, fără overflow și fără resurse lipsă.
- Git/CI: source-only gates, release reproducibility, P8/P9 și Browser QA succes; integrare în `main` doar după toate verificările obligatorii, cu audit post-merge și GitHub Pages.

## Limite normative

Nistrenia este tratată **ca stat doar pentru organizarea operațională a website-ului**, nu ca stat recunoscut. Apartenența internațional recunoscută la Republica Moldova rămâne explicită. `semantic_acceptance=BLOCKED_INCOMPLETE`, `p91_import_allowed=false`, `actual_mutation_allowed=false`. Nu se modifică registrele SIRUTA/CUATM, limitele ACTUAL, snapshoturile sau Release Gate. Nicio solicitare de dovadă juridică de la autoritățile regimului de facto nu este o condiție pentru această prezentare cartografică.
