## Constatări

1. Identitatea unică este entity.id din actual-public-entity-v3, nu numele sau bbox.
2. Geometria fidelă masterului este în descriptorul overview/statistical ori chunk
   local/detail; master_geometry_path este referință de proveniență.
3. P8.2 feature(id) rezolvă resursa din indexul compatibil cu snapshotul, catalogul
   și hashurile. Cititorul partajat verifică SHA256 și bytes. Se selectează exact
   un Feature prin properties.entity_id, păstrând geometry și proprietățile sursei.
   Serializarea individuală diferă legitim de colecție; coordonatele nu diferă.
4. Metadata publică este separată în legal, representation, statistical, hierarchy,
   roles și validation. ID juridic pozitiv numai pentru reconciled; lipsa este null.
5. Manifestul fixează snapshot, fingerprint, public_contract, descriptorii geometrici,
   statistical_source_bundle, source bundle și review evidence. Nu se modifică.
6. P8.2 distinge neighbors, points, anomalies și otherLevels. P8.3 furnizează features,
   metrics, geometrii derivate validate și residuals; export numai după calcul reușit.
7. Getterul Măsoară copiază punctele WGS84. Se cere finished și se validează cu
   funcțiile existente, fără server, URL ori salvare implicită.
8. Leaflet folosește SVG vectorial și img externe pentru raster. Canvas poate eșua
   din cauza CORS; redimensionarea pentru print poate muta viewportul/încărca tile-uri.
   Soluție propusă: SVG local din viewportul actual, explicit fără raster, imprimare
   și PDF în document izolat, fără modificarea hărții originale.
9. OSM cere atribuire și informare ODbL. INS/BNS și nomenclatoarele statistice au
   termenii furnizorilor, fără relicențiere MIT și fără certitudine juridică inventată.
10. Managerul unic P7 rămâne proprietarul panourilor. Acțiuni compacte în card,
    comparație și măsurare; vizual în Partajare, fără comenzi noi în bara Leaflet.

## Riscuri și mitigări obligatorii

Allowlist metadata/adrese, textContent, nume cu ID și fără traversal/control,
neutralizare formule CSV, UTF8/BOM și CRLF pentru Excel. Fără obiecte ambigue în CSV.
Fail closed la geometrie absentă, hash invalid, snapshot incompatibil; fără bbox,
simplificare, snapping, reproiectare, eliminarea găurilor sau corecții geometrice.
Serialization și Blob dublează memoria: plafon explicit, blocare descărcări concurente,
revocare URL, fără preîncărcare corpus și fără al doilea cache persistent.
Clipboard/print/Blob pot lipsi: mesaje role=status și text selectabil pentru raport.
Details nativ, ținte 44px și focus păstrat. Vizualul trebuie să includă toate straturile
vizibile și evidențierile ori să refuze explicit captura; rasterul este omis declarat.
